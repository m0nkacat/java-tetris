# 🧱 Java Tetris

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)
![Swing](https://img.shields.io/badge/Swing-GUI-555)

**RU** | [EN](#english)

Классический тетрис на Java Swing.

- 🎮 Управление стрелками
- 🔄 Вращение фигур, очистка заполненных линий
- 🖼️ Отрисовка игрового поля через `JPanel` и игровой цикл на `Timer`

**Запуск:** скомпилируй `src/` и запусти `Tetris_gui`:
```bash
javac -d out src/*.java && java -cp out Tetris_gui
```

---

## English

Classic Tetris written in Java Swing: arrow-key controls, piece rotation and line clearing, rendered on a `JPanel` with a `Timer`-driven game loop.

**Run:** `javac -d out src/*.java && java -cp out Tetris_gui`
